# ==============================================
# かけらクイズの問題
# ==============================================
# 書き方
#   ## ジャンル名            ここから下はこのジャンルの問題（新しい見出しを書くとジャンルが増える）
#   答え / 別解 / 別解 ★★    問題の1行目。正解にしたい別の書き方を / で区切る。行末の★の数が難易度（1〜3）
#   - ヒント                 6個以上書く（多いときは毎回ランダムに選ばれる）
#   問題と問題の間は空行をあける
#
# ひらがな・カタカナ・全角半角・空白・「ー」の違いは自動で同じとみなすので、
# 別解には「漢字」「よくある別名」などを書けばよい（例：おにぎり / おむすび）。
# 答えに漢字があるときは、ひらがなの読みを必ず別解に書く（例：北海道 / ほっかいどう）。
#
# ヒントは「答えの説明」ではなく「答えから連想するもの」を書く
#   ×「白と黒の体をしている」  ○「オセロ」
#   ×「竹や笹を食べる」        ○「笹」
#   ・1つだけでは答えが決まらないもの（「上野」だけならパンダとは限らない）
#   ・2〜3個合わせると「あっ」とつながるもの
#   ・ヒントに答えの言葉そのものを書かない
#
# 難易度の目安
#   ★    だれでも知っている答え。連想もまっすぐ
#   ★★   答えは知っているが、連想が少しひねってある
#   ★★★  答えを思いつきにくい、または連想がかなり遠い
# ==============================================
