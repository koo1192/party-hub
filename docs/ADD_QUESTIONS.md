# かけらクイズの問題の増やし方

問題はすべて [`public/games/kakera/questions.txt`](../public/games/kakera/questions.txt) という1つのテキストファイルに入っています。
このファイルに書き足すだけで問題が増えます。プログラムを触る必要はありません。

## 書き方

```
## 動物

パンダ / ジャイアントパンダ
- 体の色は2色
- 上野動物園の人気者
- 主食は植物
- 目のまわりに特徴がある
- クマのなかま
- 中国から贈られることがある
```

- `## ジャンル名` … 見出しの下にある問題がそのジャンルになります。**新しい見出しを書くと、ゲームのジャンル選びのボタンも自動で増えます。**
- 1行目 … 答え。正解にしたい別の書き方があれば `/` で区切って並べます（例：`おにぎり / おむすび`）。
  - ひらがな・カタカナ・全角半角・空白・「ー」の違いは自動で同じとみなすので、書かなくて大丈夫です。
- `- ` で始まる行 … ヒント。**6個以上**書きます。7個以上書くと、毎回その中からランダムに選ばれます。
- 問題と問題の間は**空行**をあけます。

### いいヒントのコツ

- 1つだけでは答えが決まらないようにする（「上野動物園の人気者」だけではパンダとは限らない）
- 2〜3個合わせると絞れて、全部そろえば1つに決まるようにする
- 見た目・場所・使い方・関係のあるもの、など違う方向から書く
- ヒントに答えの言葉そのものを書かない

## 方法1: GitHub のサイトで直接編集する（PCがなくてもできる）

1. https://github.com/koo1192/party-hub/blob/main/public/games/kakera/questions.txt を開く
2. 右上の鉛筆マーク（Edit）を押す
3. 書き足す
4. 右上の「Commit changes…」を押し、もう一度「Commit changes」を押す
5. 1〜2分で https://koo1192.github.io/party-hub/ に反映される

スマホのブラウザからでも同じようにできます。

## 方法2: PCで編集して確かめてから公開する

1. `public/games/kakera/questions.txt` をメモ帳などで編集して保存する（文字コードは UTF-8）
2. 書き方が正しいかチェックする

   ```bash
   npm run check
   ```

   「OK! 問題はありません。」と出ればよい。エラーが出たら、書かれている行を直す。
3. `npm start` で http://localhost:8787 を開き、実際に遊んで確かめる
4. コミットして push すると公開される

## 方法3: Claude に作ってもらう

Claude Code に「かけらクイズに○○のジャンルの問題を10問追加して」と頼めば、
このファイルの書き方に合わせて追加し、`npm run check` で確かめるところまでやってくれます。
