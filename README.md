# 🧩 かけらクイズ

2〜6人が各自のスマホで遊ぶ、協力型のパーティークイズ。インストール不要で、スマホのブラウザで遊べます。

## ルール

- 1問ごとに6つのヒント（かけら）が、全員のスマホにバラバラに配られる。
- 自分のかけらを声に出して伝え合い、6つの選択肢から答えを1つに絞る。
- 全員が同じ選択肢をタップすると回答が確定する。
- 制限時間は90秒。時間切れなら多数決で、同数ならハズレ。
- 10問中の正解数がチームのスコア。問題は25問の中からランダムに出る。

## 仕組み

- 画面は素のHTML/CSS/JSだけで作っていて、ビルドは不要（`public/`）。
- 部屋を作った人（ホスト）の端末がゲームの進行を受け持ち、Supabase Realtime の broadcast で全員に状態を送る。DBやテーブルは使わない。
- `public/config.js` が空なら「ローカルモード」になる。この場合は BroadcastChannel を使うので、同じブラウザのタブ同士でしか遊べない（動作確認用）。

| ファイル | 役割 |
| --- | --- |
| `public/app.js` | 画面と操作 |
| `public/host.js` | ホスト側の進行（ヒントの配布、投票、判定、得点） |
| `public/transport.js` | 通信（Supabase か BroadcastChannel） |
| `public/questions.js` | 問題データ（追加はここに書く） |
| `server.mjs` | 依存パッケージのない静的サーバー（Wi-Fi内で遊ぶとき用） |

## 1. Supabase を設定する（スマホで遊ぶのに必要）

1. https://supabase.com で無料のプロジェクトを作る。
2. Project Settings > API の「Project URL」と「anon public」キーを `public/config.js` に貼る。
   - anon キーはブラウザに公開する前提のキーなので、公開しても問題ない。
3. Realtime の設定は初期のままでよい。
   - Realtime Settings で「Allow public access」をオフにしている場合は、オンに戻す。

無料プランのプロジェクトは、1週間使わないと一時停止する。その場合はダッシュボードから再開する。

## 2-A. 同じWi-Fiで遊ぶ（いちばん手軽）

```bash
node server.mjs
```

表示された `同じWi-Fiのスマホから: http://192.168.x.x:8787/` のURLを、**ホストもそのURLで**開いて部屋を作る。そうするとQRコードがスマホから開けるURLになる。

- 初回は Windows のファイアウォールの確認が出るので「プライベートネットワーク」を許可する。
- スマホがつながらないときは、PCとスマホが同じWi-Fiか、ゲスト用Wi-Fi（端末同士の通信が禁止）でないかを確かめる。

## 2-B. ネットに公開して遊ぶ（外出先でも使える）

`public/` フォルダをそのまま静的ホスティングに置けばよい。どれも無料で使える。

- **Netlify Drop**: https://app.netlify.com/drop に `public` フォルダをドラッグ＆ドロップする。
- **Cloudflare Pages / GitHub Pages**: `public` を公開フォルダに指定する。

公開されたURLを開いて部屋を作れば、QRコードやルームコードでほかの人も参加できる。

## ローカルでの動作確認

`config.js` が空のまま `node server.mjs` を起動し、同じブラウザで http://localhost:8787 をタブ3つで開く。1つで部屋を作り、残りの2つでルームコードを入れて参加する。

## 問題の追加

`public/questions.js` に、選択肢6つとヒント6つを書き足す。ヒントは「1つだけでは答えが決まらず、全部合わせると1つに絞れる」ようにする。多くのヒントは不正解の選択肢を1〜2個消すものにし、1〜2個を雰囲気ヒントにするとちょうどよい。
